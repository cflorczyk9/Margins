You have a vault

Easiest: download for Claude Desktop

Double-click to install. Pre-bundled with everything Margins needs. Claude Desktop will show the Margins logo in your Connectors list.

Download .mcpb (latest)

Open the file with Claude Desktop, point it at your vault path when prompted, restart Claude (Cmd-Q + reopen).

Or, via CLI (Claude Code users + terminal lovers)

npm install -g margins-mcp

Then find your vault path in Obsidian (right-click vault → Reveal in Finder) and run:

margins-mcp install --vault /absolute/path/to/your/vault

The installer writes the configs for Claude Desktop and Claude Code, scaffolds raw/ + proposed/ + .margins/ in your vault, and runs a verification probe.

Updates

Margins surfaces an update hint in margins_start when a newer version is available. CLI install: run margins-mcp install --update. Desktop install: re-download the .mcpb above and double-click.
