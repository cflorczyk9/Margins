You have a vault

Three commands and a restart. The whole thing takes about ninety seconds.

1. Install globally

npm install -g margins-mcp

2. Find your vault path

In Obsidian, right-click the vault in the file tree → Reveal in Finder (macOS) or Show in Explorer (Windows). Copy the absolute path.

Common locations: ~/Documents/MyVault, ~/Library/CloudStorage/iCloudDrive/Obsidian/MyVault, %USERPROFILE%\Documents\MyVault.

3. Run the installer

margins-mcp install --vault /absolute/path/to/your/vault

The installer detects Claude Desktop and Claude Code, writes the config files, scaffolds raw/ + proposed/ + .margins/ in your vault, and runs a verification probe. Restart Claude Desktop (Cmd-Q, not just close the window).

4. Try it

Open a new Claude conversation:

Use margins to give me a summary of my recent notes.

Margins scaffolds the vault in your browser. Pick a parent folder; Margins creates a Margins/ directory inside with the right structure.

2. Install and connect

Open a terminal and run:

npm install -g margins-mcp
margins-mcp install

The installer auto-detects ~/Margins/ and connects it to Claude Desktop / Claude Code. Restart Claude Desktop when it finishes.
