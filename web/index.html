Margins

Use your Claude Pro or Max subscription on your Obsidian vault. No API key. No per-token costs. Your files stay on your disk.

margins-mcp is a small Node program that sits between Claude (Desktop or Code) and your Markdown vault. Claude reads your notes through it. Your subscription pays for inference. Files never leave your machine.

Get started

Pick the row that matches your setup:

I have a vault already

You use Obsidian, or you have a folder of Markdown files somewhere. You know the path.

I'm starting fresh

No vault yet. Margins will scaffold one for you, right in this browser, then hand you the install command.

You have a vault

Install margins-mcp globally, then run the installer pointing at your vault.

1. Install

npm install -g margins-mcp

2. Find your vault path

In Obsidian, right-click your vault in the file tree → Reveal in Finder (macOS) or Show in Explorer (Windows). Copy the absolute path.

Common paths: ~/Documents/MyVault, or ~/Library/CloudStorage/iCloudDrive/Obsidian/MyVault for iCloud-synced vaults on Mac.

3. Run the installer

margins-mcp install --vault /absolute/path/to/your/vault

The installer detects Claude Desktop and Claude Code, writes the right configs, scaffolds raw/ + proposed/ + .margins/ in your vault, and runs a verification probe. Restart Claude Desktop (Cmd-Q) and you're done.

4. Try it

Open a new Claude conversation:

Use margins to give me a summary of my recent notes.

You're starting fresh

Margins will scaffold a vault in your browser using the File System Access API. Pick a parent folder (e.g. your home directory); Margins creates a Margins/ folder inside it with the right structure.

1. Scaffold the vault

2. Install and connect

Open a terminal and run:

npm install -g margins-mcp
margins-mcp install

The installer detects ~/Margins/ automatically (the folder you just scaffolded) and connects it to Claude Desktop / Claude Code. Restart Claude Desktop after it finishes.
