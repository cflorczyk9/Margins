Install for Claude Desktop.

Download for Claude Desktop ↓

~28 MB·macOS & Windows·MIT

Double-click. Pick a folder. Ask Claude. Margins shows up in your Connector list with its logo.

Install via npm.

01 npm install -g margins-mcp
02 margins-mcp install --vault /absolute/path/to/your/files

The installer writes configs for Claude Desktop and Claude Code, scaffolds raw/, proposed/, and .margins in your folder, and verifies. To update later: margins-mcp install --update.
