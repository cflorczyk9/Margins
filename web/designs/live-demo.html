Margins · live demo

Claude works on your Obsidian vault, with your existing subscription.

Reads your notes, writes back to disk, asks before editing. No API key, no embedding pipeline, no copy of your files in the cloud.

Claude · vault/

This is a scripted demo. The real install is below — it talks to your local files, not this page.

Install Margins

Pick the row that fits. You can switch later.

1. Download for Claude Desktop

Double-click to install. Pre-bundled, no terminal needed. Claude Desktop shows Margins in its Connectors list.

Download margins-mcp.mcpb

Open the file with Claude Desktop, point it at your vault when prompted, then restart Claude (Cmd-Q, reopen).

2. Try it

In a fresh Claude conversation:

Use margins to give me a summary of my recent notes.
CLI install (Claude Code, terminal preferred)

Install globally:

npm install -g margins-mcp

Find your vault path in Obsidian (right-click vault → Reveal in Finder), then run:

margins-mcp install --vault /absolute/path/to/your/vault

The installer writes the configs for Claude Desktop and Claude Code, scaffolds raw/, proposed/, and .margins/ inside your vault, and runs a verification probe.

Updates: margins-mcp install --update for CLI; re-download the .mcpb for Desktop.

1. Scaffold a vault

Margins creates a Margins/ folder with wiki/, raw/, proposed/, .margins/, plus CLAUDE.md and operator-manual.md inside.

2. Install and connect

In a terminal:

npm install -g margins-mcp
margins-mcp install

The installer auto-detects ~/Margins/ and connects it to Claude Desktop and Claude Code. Restart Claude Desktop when it finishes.

3. Try it

In a fresh Claude conversation:

Use margins to help me start writing in my new vault.

Works with Claude Desktop and Claude Code on macOS, Windows, Linux. Needs Claude Pro ($20/mo) or Max. Uses your existing subscription — no API key, no per-token costs. Browser (claude.ai web) isn't supported yet.
