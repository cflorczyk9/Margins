Install

Two ways in. Pick whichever fits.

Claude Desktop · one file Double-click margins-mcp.mcpb, point at your vault, restart.
Download .mcpb

After it installs, quit Claude with Cmd-Q and reopen. You'll see Margins in the Connectors list. To try it, open a new chat and ask: "Use margins to summarize my recent notes."

Install via CLI (Claude Code, terminal lovers) +

Install the package globally:

npm install -g margins-mcp

Find your vault path (in Obsidian: right-click the vault → Reveal in Finder), then run:

margins-mcp install --vault /absolute/path/to/your/vault

The installer writes the Claude Desktop and Claude Code configs, scaffolds raw/, proposed/, and .margins/ inside the vault, and runs a verification probe.

To update later: margins-mcp install --update.

No vault yet? Scaffold one in your browser. +

Pick a parent folder; Margins creates a Margins/ directory with the right shape (wiki, raw, proposed, .margins, plus a starter CLAUDE.md).

Then connect it with the CLI:

npm install -g margins-mcp
margins-mcp install

The installer auto-detects ~/Margins/ and wires it to Claude. Restart Claude Desktop when it finishes.

What it is

An open-source MCP server. About 700 lines of TypeScript. It runs locally on your machine, exposes six tools to Claude (read, search, list, propose a write, list proposals, accept), and uses your existing Claude Pro or Max subscription. No API key. No embedding pipelines. No vendor cloud sitting between you and your files.

Vault content never leaves your disk. Claude reads files through the connector; it never sees your folder unless you tell it to look.
