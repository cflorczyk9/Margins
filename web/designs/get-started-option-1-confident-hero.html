What you'll see after install
› Already installed? Update with one command
Run margins-mcp install --update in your terminal. Your vault, configuration, and connector pairings are preserved. The MCP server restarts automatically; you don't need to touch Claude Desktop.
› No vault yet? Margins can scaffold one
Margins can create a starter vault for you in any folder — wiki, raw, proposed, plus a CLAUDE.md operator manual. Run margins-mcp install without --vault and follow the prompt to choose a location.
