Get started

One file, one double-click. If you already use Claude Desktop, that's all of it.

Download for Claude Desktop

Easiest

Margins ships as a single .mcpb bundle. Double-click it and Claude Desktop installs the connector. No terminal, no config files.

Download margins-mcp.mcpb ~2 MB · macOS & Windows · MIT
  1. 1 Double-click the file you just downloaded. Claude Desktop opens and installs it.
  2. 2 Point it at your vault when Claude asks. Any folder of Markdown works — Obsidian, iCloud Drive, anywhere.
  3. 3 Ask Claude about your notes. Margins shows up in the connector list with its logo.
Prefer the terminal? Install via npm. Claude Code · CLI users

Install the package globally:

npm install -g margins-mcp

Find your vault path (in Obsidian: right-click vault → Reveal in Finder) and run:

margins-mcp install --vault /absolute/path/to/your/vault

The installer writes the configs for Claude Desktop and Claude Code, scaffolds raw/, proposed/, and .margins/ in your vault, and runs a verification probe.

Try it in any Claude conversation:

Use margins to give me a summary of my recent notes.

To update: margins-mcp install --update.

No vault yet? Margins can scaffold one for you. First-time setup

Margins creates a starter vault in the folder you pick — wiki, raw, proposed, plus an operator manual and a CLAUDE.md.

Now install the connector (the .mcpb download above is the easiest path) and point it at the Margins/ folder you just created.

Open a Claude conversation:

Use margins to help me start writing in my new vault.
Margins runs locally. No vault content leaves your machine. Privacy details · Source · npm · MIT
