Get started

Install Margins.

You saw it. Now run it on your files.

Desktop: double-click install with the .mcpb bundle. Works on macOS & Windows.

CLI: npm package, works with Claude Code or anywhere you have Node. Linux too.

Install for Claude Desktop.

Download for Claude Desktop ↓ ~28 MB · macOS & Windows · MIT

Double-click. Pick a folder. Ask Claude. Margins shows up in your Connector list with its logo.

Install via npm.

$ npm install -g margins-mcp
$ margins-mcp install --vault /absolute/path/to/your/files

The installer writes configs for Claude Desktop and Claude Code, scaffolds raw/, proposed/, and .margins in your folder, and verifies. To update later: margins-mcp install --update.
