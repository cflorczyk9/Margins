Margins

a letter, with notes

Dear reader,

I keep my thinking in a folder of Markdown files. So do you, maybe — or you have an Obsidian vault doing the same job under a friendlier name. It's a quiet, private place. Searchable. Versionable. Yours.

Meanwhile I pay $20 a month for Claude. It reads almost everything I read, drafts almost everything I draft, and answers most of my questions better than the search bar of any app I own. The one thing it doesn't see is the folder. The folder is where the memory lives.

Margins is the seam between those two things. It's a small open-source MCP connector I built to give Claude read access to my notes, plus the ability to propose writes that I either accept or throw away. Nothing is autonomous. Nothing leaves the disk. No API key, no per-token bill, no embedding pipeline to maintain.

What I wanted, honestly, was for Claude to be able to say "you wrote about this six months ago, here's the page," and for the version that gets written next to fall into the right folder with the right links. Margins is the smallest thing that makes that work. It runs locally. It speaks Markdown. It uses the subscription you already pay for.

The conversation in the right column is what Claude is actually doing while you read this — pointing at phrases, asking questions, making notes. That's the whole product, more or less. A second voice in the margin of your own thinking, useful enough to leave running.

— Connor

To get this running

two paths. pick one.

One double-click

claude desktop, easiest

Download the bundle. Double-click it. Claude Desktop will ask for your vault path, then show Margins in its connectors list.

Download .mcpb ↓

quit and reopen claude after install

Two commands

claude code + terminal people

Install once:

npm install -g margins-mcp

Then point it at your vault:

margins-mcp install --vault /absolute/path/to/your/vault

writes the configs, scaffolds raw/ proposed/ .margins/, runs a probe

I don't have a vault yet — scaffold one for me (opens in this browser)

Pick a parent folder; Margins creates a Margins/ directory inside with wiki/, raw/, proposed/, .margins/, plus a starter CLAUDE.md and operator manual.

Now connect it:

npm install -g margins-mcp
margins-mcp install

the installer auto-detects ~/Margins/ if it's there. restart claude desktop when it finishes.

what it sees Markdown files on disk. Not Notion, not Roam, not Mem.
where the data goes Nowhere. The connector runs on your machine. Your vault never leaves.
what claude can do Search, read, list recent, follow backlinks, propose new pages, propose edits, append to a daily note.
what claude can't do Edit your files directly. Every write is a proposal in proposed/ until you accept it.
where it works Claude Desktop and Claude Code. Not claude.ai in the browser (MCP isn't there yet).
