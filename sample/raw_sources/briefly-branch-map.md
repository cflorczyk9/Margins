# Briefly Branch Map

Briefly and Margins share one strategic idea: people want AI to operate on their real context without rebuilding the context in every conversation.

Briefly is closer to a polished app surface. Margins is closer to infrastructure for personal knowledge. It can begin as a folder compiler and become an MCP server later.

Version one should include skills and Markdown instructions. The language model needs an operator manual, query cookbook, command files, agent files, and an edit log. Without those, the wiki is just organized text rather than a usable AI workspace.

The first wedge is a Karpathy-style original template:

- raw_sources for untouched evidence
- wiki for durable edited knowledge
- graph metadata for links
- commands for repeatable model behavior
- edit proposals before write-back
